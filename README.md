# Memories

Audio-reactive p5 sketches migrated from the legacy `memories-no-3` / `memories-no-4` starters onto `@labcat2020/*` packages.

## Sketches

- **#MemoriesNo1** — MIDI colour flashes (from [memories-no-4](https://github.com/LABCAT/memories-no-4))
- **#MemoriesNo2** — photo-sampled particles (from [memories-no-3](https://github.com/LABCAT/memories-no-3))

## Dev

```bash
pnpm install
pnpm dev
```

Uses `@labcat2020/animation-lab`, `@labcat2020/p5.audioreactive`, and `@labcat2020/p5.audioreactive-capture` from npm.
